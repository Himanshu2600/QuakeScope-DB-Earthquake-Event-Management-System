Project Specifications & Architecture

CSE494: Intelligent NoSQL Databases • Academic Milestone Stage 3

Database Specifications

  • Database Name: quakescope_db
  • Target Collection: earthquake_events
  • Storage Engine: WiredTiger (MongoDB 8.3.7)
  • Verified Count: 19,705 documents (100% intact)
  • Validation Level: Strict (Error action)
  • Primary Key: Unique index on event_id

USGS Catalog Provenance

  • Data Source: USGS Earthquake Hazards Program
  • Catalog Name: ANSS Comprehensive Catalog (ComCat)
  • Time Span: Jan 1, 2025 to Jan 1, 2026 (365 days)
  • License: U.S. Government Public Domain
  • Max Magnitude: 8.8 Mww (Kamchatka Peninsula)
  • Negative Depths: High elevation volcanic events

Technology Stack

  • Backend: Python 3.13 + Flask 3.1
  • Database Driver: PyMongo 4.19
  • Frontend Design: Vanilla CSS3 (Apple Liquid Glass)
  • Charts & Visuals: Chart.js 4.4 + Leaflet 1.9
  • Client Scripts: Vanilla Modern JavaScript
  • Port: http://127.0.0.1:5000/
